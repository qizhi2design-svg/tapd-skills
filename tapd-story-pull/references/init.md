# TAPD 初始化说明

## 触发条件

当 `tapd info` 显示已授权，但当前空间或默认创建人仍是“未设置”时，进入这个文档。

## 未初始化时的处理

如果当前项目还没有配置空间或创建者，先执行：

```bash
tapd init
```

## 初始化目标

初始化时需要引导用户完成：

- 选择默认空间
- 选择默认创建者

## 常见问题

- 如果没有 `.tapd/config.json`，不要直接假设空间和创建者存在
- 对于 `story pull`，即使用户显式传了 `--workspace-id`，项目初始化仍然有助于减少后续交互
- 初始化后优先重新执行 `tapd info`，确认当前空间和默认创建人已设置
